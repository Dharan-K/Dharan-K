#### 🔐 Project Veil — Private Eligibility Proofs on Stellar

Privacy-focused blockchain application that enables users to prove their eligibility without revealing sensitive personal information.

* 🔐 Generates **Zero-Knowledge Proofs** using Groth16
* ⛓️ Proof verification through **Soroban smart contracts**
* 🌐 Built around the **Stellar blockchain ecosystem**
* 🛡️ Designed for privacy-preserving digital payments and eligibility verification

---

#### 🧠 Brain Tumor Prediction

CNN-based medical image classification system for detecting brain tumors from MRI scans.

* 🧠 Built using **TensorFlow, Keras and OpenCV**
* 📊 Achieved approximately **96% classification accuracy**
* 🔍 Integrated **Grad-CAM explainability**
* 🌐 Interactive interface built with **Streamlit**

---

#### 🌱 UrbanGrow — AI Smart Agriculture Monitoring

AI-powered smart agriculture platform for monitoring environmental conditions and providing intelligent farming recommendations.

* 🌡️ Monitors soil moisture, temperature and light
* 🤖 Generates AI-powered farming insights
* ☁️ Uses Firebase for authentication and real-time data
* 🌦️ Integrates weather forecasting APIs
* 💻 Built using React, Node.js and Firebase

---

#### 🔗 MediChain — Blockchain Medical Data Sharing

Blockchain-based platform for privacy-focused medical research data sharing and consent management.

* 🔐 Patient-controlled consent management
* ⛓️ Blockchain audit trail
* 🚨 Emergency consent locking
* 🗂️ Secure medical research data access
* 💬 AI-assisted information interface
